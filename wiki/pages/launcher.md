`Metin2-Launcher-GUI.bat` to okienkowy launcher dla Windows.

| Przycisk | Co robi |
|---|---|
| **1. ZAINSTALUJ / PRZYGOTUJ** | sprawdza paczkę i klienta, tworzy skrót na pulpicie |
| **2. GRAJ (SERWER + KLIENT)** | uruchamia Docker, serwer i klienta |
| **URUCHOM DOCKER** | uruchamia sam Docker Desktop |
| **ZATRZYMAJ I ZAPISZ** | bezpiecznie zatrzymuje serwer; nigdy nie kasuje postaci ani postępu botów |
| **OTWÓRZ PANEL WWW** | otwiera panel w przeglądarce ([Panele WWW](/mt2009plus/panele/)) |
| **WYBIERZ KLIENTA** | wskazuje folder klienta gry |
| **SPRAWDŹ AKTUALIZACJE** | sprawdza i instaluje aktualizacje serwera i klienta |
| **LICZBA BOTÓW (0–2500)** | ile botów żyje na świecie, osobno dla królestw, drugi kanał ([Boty](/mt2009plus/boty/)) |
| **POZIOM TRUDNOŚCI** | czasy u Biologa, Stajennego i między księgami ([Poziom trudności](/mt2009plus/poziom-trudnosci/)) |
| **KOPIA / NOWY ŚWIAT** | kopia świata do zip albo nowy, pusty świat ([Kopia świata](/mt2009plus/kopia-swiata/)) |
| **IMPORTUJ BAZĘ** | wczytuje zapisaną kopię świata |
| **COOP: GRA ZE ZNAJOMYMI** | udostępnia twój świat znajomym ([COOP](/mt2009plus/coop/)) |
| **DANE DO BAZY (NAVICAT)** / **NAPRAW DOSTĘP DO BAZY** | dostęp do bazy danych ([Baza danych](/mt2009plus/baza-danych/)) |
| **PANEL GM F9 (TEST)** | panel GM w kliencie |
| **ZBIERZ / WYŚLIJ LOGI**, **DIAGNOSTYKA**, **OTWÓRZ LOG**, **FOLDER LOGÓW** | gdy coś nie działa ([Problemy](/mt2009plus/problemy/)) |
| **JĘZYK / LANGUAGE** | język launchera (polski / angielski) |

Po kliknięciu **OTWÓRZ PANEL WWW** launcher pokazuje hasło do panelu (można je tam też zresetować).
