# MT2009_PLUS_SERVER_CONFIG_V1: the server configurations ("Konfiguracja serwera").
#
# One file read by two programs: the advanced panel's page "Konfiguracja
# serwera" (server_config.py) and the VPS installer (linux-port/tools/
# vps-install.sh --profile NAME, which reads only the "env" and "rate" lines
# of one profile, for a world not made yet). A new configuration is a new
# [profile ...] block here - no code. test_server_config.py fails when a
# line here is anything the panel would refuse.
#
# [profile <id>]             id: a-z, 0-9, _ (1-32)
#   title = ...              the card's name
#   desc = ...               one paragraph, Polish
#   env KEY = value          a .env line, checked by env_schema.py like the
#                            .env editor checks it; never a password, a port,
#                            an address or a hidden / read-only setting
#   rate exp|drop|yang = N   the world's rates in percent (1-10000, yang up
#                            to 1000); a running world through "Gra i serwer
#                            -> Raty" (one restart), a new one through M2_RATE_*
#   event KIND DAYS FROM TO VALUE [MAP [TARGET]]
#                            a row of the events planner, as the panel writes
#                            playerbot_events.tsv (DAYS * or 1..7, 1 = Monday;
#                            chestdrop: VALUE per mille, MAP the item's vnum,
#                            TARGET 0 every monster and Metin, 1 bosses and
#                            Metins only, 2 ordinary monsters only). The rows
#                            are added to the planner; nothing there is removed.
#   worldboss = always|schedule|off
#                            the World Boss's mode (the "Boss Świata" page:
#                            always on, only in the planner's windows, off)
#
# [group <id>]               a card of the page's "Ustawienia" part
#   title = ... / desc = ...
#   keys = KEY KEY ...       .env settings shown and saved like the .env editor
#   link = endpoint | text   a page of the panel that holds the rest
