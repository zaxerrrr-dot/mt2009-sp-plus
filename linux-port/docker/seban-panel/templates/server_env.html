Ustawienia serwera (.env)

Wszystkie {{ field_count }} parametry pliku linux-port/docker/.env w jednym miejscu: liczba botów, moduły, porty, panele, baza i aktualizacje. Zmiany zapisuje aktualizator serwera – przed zapisem robi kopię .env, zmienia tylko wskazane linie (komentarze zostają), a potem uruchamia ponownie wyłącznie usługi, które czytają zmienione ustawienia.

Aktualizator działa, ale w starszej wersji i nie obsługuje jeszcze tej strony. Uruchom go ponownie (polecenia poniżej – „uruchom ponownie”).

{% else %}

Zmiany na tej stronie zapisuje do pliku .env usługa aktualizator (kontener updater) – jedyny element serwera z dostępem do Dockera. Panel celowo go nie ma, więc bez aktualizatora może tylko pokazać ustawienia.

{% endif %}

Od tej wersji aktualizator uruchamia się sam: na VPS po instalacji i po każdej aktualizacji (update.sh), na Windowsie przy każdym kliknięciu GRAJ w launcherze. Domyślnie nie instaluje aktualizacji (tylko zapisuje ustawienia), chyba że włączysz „Instalacja aktualizacji z panelu” (M2_UPDATE_APPLY=1). Jeśli mimo to nie działa – zrób to raz ręcznie:

🐧 Serwer na VPS / Linuksie (SSH)
  1. Zaloguj się na VPS przez SSH (np. PuTTY albo ssh root@ADRES_VPS).
  2. Przejdź do folderu serwera (tego z plikiem VERSION i folderem linux-port) i uruchom aktualizator: 
    cd /ścieżka/do/serwera        # np. cd ~/Serwer albo cd /opt/metin2
sh linux-port/tools/update.sh updater
  3. Gdy Twoja wersja nie zna jeszcze polecenia updater, zrób to bezpośrednio przez Dockera: 
    cd /ścieżka/do/serwera/linux-port/docker
M2_UPDATE_STACK_DIR="$(cd ../.. && pwd)" M2_UPDATE_WATCH_UPDATES=0 \
  docker compose --profile update up -d --build updater
  4. Uruchom ponownie (np. po aktualizacji albo gdy jest „w starszej wersji”): 
    cd /ścieżka/do/serwera/linux-port/docker
docker compose --profile update up -d --force-recreate updater
  5. Sprawdź: docker ps --filter name=updater – powinien być Up (healthy). Potem kliknij „Sprawdź ponownie” poniżej.
🪟 Serwer na Windows (localhost, Docker Desktop)
  1. Upewnij się, że Docker Desktop jest uruchomiony (ikona wieloryba przy zegarze, status „Engine running”).
  2. Najprościej: zaktualizuj serwer launcherem (Metin2-Launcher.bat → Aktualizuj) i kliknij GRAJ – launcher sam uruchomi aktualizator po starcie serwera.
  3. Albo ręcznie: otwórz folder serwera w Eksploratorze, kliknij pasek adresu, wpisz powershell i Enter, a potem: 
    powershell -ExecutionPolicy Bypass -File .\start-server.ps1 -UpdaterOnly
  4. W Docker Desktop → Containers powinien pojawić się kontener …-updater ze statusem Running. Kliknij „Sprawdź ponownie” poniżej.

Nie chcesz aktualizatora? Ustaw w linux-port/docker/.env M2_UPDATE_AUTOSTART=0 – wtedy nie startuje sam, a tę stronę można tylko czytać (plik .env zmieniasz ręcznie).
