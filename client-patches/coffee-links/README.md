# Odnośniki wsparcia MT2009 Plus

`client-coffee-links.patch` ustawia adres
`https://buycoffee.to/mt2009plus` w trzech miejscach klienta:

- przycisk `Facebook` na ekranie logowania,
- kategoria `Doładuj SM` w ItemShopie,
- przycisk zakupu w widoku `Kup Premium`.

Gotowa paczka `root.data/root.index` jest przygotowana w kliencie testowym.
Zmiana nie jest jeszcze publikowana w manifeście aktualizacji.
